# Ecommerce Fulfillment Inventory-Loss Recovery

Recover inventory value for inbound shortages, warehouse losses, damage, disposal, and incorrect reimbursements.

**Primary buyer:** Marketplace sellers and omnichannel retailers. **Evidence:** fulfillment agreements, inbound shipments, receiving, inventory adjustments, warehouse events, damage, loss, removals, reimbursements, and settlements.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Fulfillment agreement library
- SKU cost registry
- Inbound shipment ingestion
- Receiving reconciliation
- Inventory adjustment tracking
- Warehouse loss detection
- Damage event evidence
- Disposal authorization control
- Removal order matching
- Reimbursement eligibility
- Replacement cost calculation
- Provider claim generation
- Denial appeal workflow
- Cash reimbursement matching
- Provider SKU analytics

Run `./start.sh`, then open <http://127.0.0.1:4732>. API: `5732`.

Administrator: `runtime-admin@example.com` / `LocalDemo!2026`. Operator and reviewer credential buttons are available on the login page.
